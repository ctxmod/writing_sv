Granskningsanteckningar över malltexten i samma källa:

1. Tidsformatet blandar linjer: klockslagen är sifferformer medan
   datumet är utskrivet – välj en linja och håll den.
2. Formuleringen ”påverkas inte” lovar mer än ett underhållsfönster
   kan lova; mjuka ned till ”beräknas inte påverkas”.
3. Förlängningsklausulen tystnar om bokningarna när fönstret
   förlängs; komplettera med vad som gäller då.
4. Texten saknar kontaktuppgift; en fråga behöver någonstans att
   landa.
