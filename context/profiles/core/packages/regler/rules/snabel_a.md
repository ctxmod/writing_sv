# Bokstavligt snabel-a

Ett bart `@` i triggerposition, i början av en mening eller som
fristående omnämnande, tolkas som en citeringsnyckel och kan stoppa
renderingen med CTX-REF013. Skriv det i en kodspann eller som `\@`.
Regeln och dess test står i skrivmodulens `at_sign_literals` (modulen
`writing`, profilen `core`, paketet `mechanics`) och gäller oförändrade
för svensk text.
